# اجرا روی GitHub و Vercel

## محلی

Node.js 22 و npm:

```sh
npm ci
npm run dev
```

آدرس پیش‌فرض `http://127.0.0.1:3000` است. dev به loopback محدود و ورود در آن باز است. پیش‌نمایش production با `npm run build` و `npm start` اجرا می‌شود و ورود لازم دارد.

## تنظیمات محیطی

فایل `.env.example` نمونه است. متغیرهای واقعی را در `.env.local` و تنظیمات پروژهٔ Vercel ثبت کن؛ فایل واقعی و کلیدها را به Git اضافه نکن.

| متغیر | کاربرد |
|---|---|
| `SITE_PASSWORD` | رمز ورود شخصی به سایت |
| `SESSION_SECRET` | رشتهٔ تصادفی حداقل ۳۲ نویسه‌ای برای امضای نشست |
| `GROQ_API_KEY` | اختیاری؛ فعال‌سازی همراه مطالعه |
| `GROQ_MODEL` | اختیاری؛ پیش‌فرض `llama-3.3-70b-versatile` |

برای تولید secret می‌توانی `openssl rand -hex 32` اجرا کنی. مقدار تولیدشده را خصوصی نگه دار. بدون رمز و secret معتبر، نسخهٔ production جزوه‌ها را باز نمی‌کند. تغییر رمز یا secret، نشست‌های قبلی را نامعتبر می‌کند. کوکی production از HttpOnly و Secure استفاده می‌کند؛ محیط واقعی باید HTTPS باشد.

## انتشار

1. یک repository **خصوصی** در GitHub بساز و این پوشه را به آن push کن؛ پوشهٔ `content` و `imports` حاوی متن شخصی گفت‌وگو است. مخزن این پروژه هنوز به remote متصل نشده است.
2. repository را در Vercel import کن؛ Framework Preset روی Next.js و Root Directory روی ریشهٔ پروژه باشد.
3. Install: `npm ci`، Build: `npm run build`؛ Output Directory را روی پیش‌فرض Next.js بگذار. `dist/public` مربوط به خروجی مستقل محتواست، خروجی این سایت نیست.
4. رمز، secret و در صورت نیاز کلید Groq را برای محیط‌های موردنظر تنظیم کن و Deploy را اجرا کن.
5. ورود و بازشدن درس را روی HTTPS بررسی کن. با هر push، محتوای JSON جدید همراه برنامه deploy می‌شود.

نیازی به دیتابیس برای این نسخه نیست. Vercel محل نوشتن محتوای جدید نیست؛ مسیر تغییر داده از GitHub می‌گذرد. یادداشت‌های شخصی و مرور روی مرورگر همان دامنه ذخیره می‌شوند؛ انتقال بین دامنهٔ preview و production یا بین دستگاه‌ها خودکار نیست.

دستیار هنگام سؤال، بخشی از جزوهٔ انتخابی را به API سرویس Groq می‌فرستد؛ کلید سرویس فقط سمت سرور است. بدون کلید، وضعیت اتصال صادقانه در رابط نمایش داده می‌شود. این مرحله شامل ساخت حساب Vercel، ایجاد remote یا انتشار آنلاین نشده است.
