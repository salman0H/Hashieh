# معماری حاشیه

لایه‌ها مستقل‌اند:

- `content/` و `schemas/`: قرارداد دادهٔ قابل انتقال به درس‌های دیگر؛ به React وابسته نیست.
- `app/lib/repository.ts`: آداپتور سرور از JSON به مدل نمایش؛ بدنهٔ جزوه‌ها در bundle عمومی نیست. داده با هر deploy تازه می‌شود.
- `app/lib/presentation.ts`: نام‌های نمایشی فارسی، دسته‌ها و چیدمان گراف؛ مستقل از محتوای اصلی.
- `app/components/Board.tsx`: نقشهٔ قابل pan/zoom با React Flow و ورود برگه‌ها با GSAP. هفت مبحثِ منتخب برای نمای اول؛ همهٔ ۴۵ مبحث در نمای فهرست قابل انتخاب‌اند. خط‌های این نقشه ارتباط بصری موضوع‌ها هستند، پیش‌نیاز تأییدشده نیستند.
- `app/components/Workspace.tsx`: پوسته و هدایت بین صفحات. درس، واژه‌نامه، مرور، یادداشت، جست‌وجو و دستیار هر کدام component مستقل دارند و از مدل‌های مشترک مصرف می‌کنند.
- `app/components/usePersonal.ts`: آداپتور پیشرفت، نشان‌ها، یادداشت‌ها، زمان مرور و پوسته در localStorage، کلید نسخه‌دار `hashiyeh.v1`. این داده بین دستگاه‌ها همگام نمی‌شود. خروجی JSON از صفحهٔ یادداشت‌ها قابل دریافت است؛ بازیابی از فایل هنوز پیاده نشده.
- `app/api/content`: تنها مسیر خواندن جزوه و واژگان؛ کنترل ورود برای هر درخواست.
- `app/api/tutor`: اتصال سروری Groq با متن حداکثر سه جزوهٔ مبحث جاری؛ پاسخ ساختگی ندارد. این پیاده‌سازی embedding/RAG یا جست‌وجوی معنایی نیست. ارسال سؤال فقط با اقدام خود کاربر انجام می‌شود.
- `app/lib/auth.ts`: فضای شخصی تک‌کاربره با رمز مشترک و کوکی امضاشدهٔ هفت‌روزه. سامانهٔ حساب‌های چندکاربره نیست.

## تجربهٔ مطالعه

نمای تخته، معرفی کوتاه و فرمول مبحث را کنار بخشی از متن واقعی می‌آورد. «متن کامل جزوه» تمام بخش‌های پاسخ‌های مرتبط را بدون حذف متن در اختیار می‌گذارد؛ چون یک پیام ممکن است چند موضوع داشته باشد، بعضی جزوه‌ها در چند مبحث تکرار می‌شوند. تمرین‌های تازه از پاسخ‌نامه‌های ناقص منبع جدا هستند. پاسخ‌نامهٔ بدون صورت سؤال هرگز به آزمون قابل نمره‌دادن تبدیل نمی‌شود.

مرور، حداکثر ده واژهٔ سررسیدشده از مجموعهٔ اولویت A را نشان می‌دهد. «دوباره» یک روز و «بلدم» سه روز بعد برنامه‌ریزی می‌کند؛ این الگوریتم ساده است و ادعای FSRS/SM-2 ندارد. تلفظ از موتور گفتار دستگاه استفاده می‌کند.

پوستهٔ روشن و تیره، منوی موبایل، نمای فهرست جایگزین گراف، کنترل‌های صفحه‌کلید، محصورکردن focus در مودال و `prefers-reduced-motion` پشتیبانی می‌شوند. فونت‌ها محلی‌اند و برای build به Google Fonts نیازی نیست.

## افزودن درس و جلسه

برای جلسهٔ زبان جدید از `templates/session.bundle.json` و `docs/WEEKLY-WORKFLOW.md` استفاده کن؛ سپس اعتبارسنجی و build. مبحث‌های تازهٔ همان موضوع خودکار در فهرست می‌آیند. برای نمایش در نمای منتخب گراف، مختصات و اتصال‌ها را در presentation تنظیم کن.

قرارداد محتوا از subjectهای دیگر پشتیبانی می‌کند. رابط نسخهٔ اول برای اتاق انگلیسی تنظیم شده است؛ پیش از افزودن اتاق دوم، انتخاب subject و فیلتر repository را به پوسته اضافه کن. داده و آداپتور نیاز به بازنویسی بنیادی ندارند.

## بررسی‌ها

`npm test` یکپارچگی محتوا، حفظ دقیق استخراج، مراجع و جلوگیری از انتشار محتوای خصوصی را بررسی می‌کند. `npm run typecheck` بررسی نوع و `npm run build` ساخت production است. `npm run test:app` به build موجود نیاز دارد و دسترسی بستهٔ پیش‌فرض، ورود با رمز، cookie، API خصوصی، جست‌وجو و خطاهای سرویس را با سرور واقعی بررسی می‌کند.

این نسخه پایهٔ اجرایی و بصری پروژه است؛ ارسال به showcase به طراحی محتوای اختصاصی بیشتر، بازبینی آموزشی و پولیش تعامل‌ها در مراحل بعد نیاز دارد.
